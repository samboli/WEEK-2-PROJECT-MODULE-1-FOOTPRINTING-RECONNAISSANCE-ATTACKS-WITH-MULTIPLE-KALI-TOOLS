# WEEK-2-PROJECT-MODULE-1-FOOTPRINTING-RECONNAISSANCE-ATTACKS-WITH-MULTIPLE-KALI-TOOLS
FOOTPRINTING &amp; RECONNAISSANCE ATTACKS WITH MULTIPLE KALI TOOLS
What is the purpose of this?

the purpose of this is to carry out footprint and reconnaissance attackes using multiple kali tools
the following tasks were carried out: 
Task 1. I Run whois to find the domain registration details.
Task 2. I Run whatweb to fingerprint the web technologies.
Task 3. I Run nslookup to resolve the domain to its IP address.
Task 4. I Run curl -I to read the HTTP response headers.
Task 5. I Run wafw00f to detect a Web Application Firewall.
Task 6. I Run dnsrecon to enumerate all DNS records.
